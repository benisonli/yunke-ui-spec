# Yunke UI Spec

A reusable UI specification package for Yunke CRM, based on:

- existing Yunke design guideline assets
- live CRM page research
- Ant Design-based frontend conventions

## Included files

- `yunke-crm-design-spec.md` — main design specification
- `yunke-crm-design-spec.html` — HTML version
- `yunke-crm-design-spec.pdf` — PDF version
- `yunke-ant-design-token-mapping.md` — Ant Design token and component mapping
- `yunke-uiuxpromax-prompt-template.md` — prompt template for UIUXProMax / AI page generation
- `team-ready-summary.md` — concise team-ready summary
- `source-images/` — source reference images

## Positioning

This package is intended for:

- product managers
- UI designers
- frontend engineers
- AI page generation workflows
- external collaborators

## Design direction

Unified direction:

> Ant Design B2B admin best practices + Yunke brand blue system + data-driven CRM scenarios + light AI-enhanced visual language

## Notes

This repository is a document/spec package, not an executable skill.
